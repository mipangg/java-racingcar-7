# 자동차 경주

## 기능 구현 목록

### 자동차
[x] 각 자동차에 5자 이하의 이름을 부여할 수 있다.  
[x] 0에서 9 사이의 무작위 값이 4 이상일 경우 전진할 수 있다.   
[x] 0에서 9 사이의 무작위 값이 4 미만일 경우 전진할 수 없다.   


### 자동차 경주
[x] 주어진 횟수 동안 n대의 자동차는 경주한다.       
[x] 자동차 경주 게임을 완료한 후 우승자를 선별할 수 있다.    
[x] 우승자는 한 명 이상일 수 있다.


### 입출력
[x] 자동차 이름은 쉼표(,)를 기준으로 구분한다.   
[x] 자동차 이름은 5자 이하만 가능하다.   
[x] 자동차 이름 입력 시 쉼표 사이의 공백은 없는 이름으로 취급한다.   
[x] 사용자는 몇 번의 이동을 할 것인지를 입력할 수 있다.   
[x] 전진하는 자동차를 출력할 때 자동차 이름을 같이 출력한다.   
[x] 차수별 경주가 끝날 때 마다 결과를 출력한다.   
[x] 자동차 경주 게임을 완료한 후 누가 우승했는지를 알려준다.    
[x] 우승자가 여러 명일 경우 쉼표(,)를 이용하여 구분한다.
[x] 사용자가 잘못된 값을 입력할 경우 `IllegalArgumentException`을 발생시킨 후 애플리케이션은 종료되어야 한다.    
[x] 자동차 이름으로 빈 값이 입력되면 예외가 발생한다.
